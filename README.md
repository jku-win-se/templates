# JKU WIN-SE LaTeX Templates

> [!IMPORTANT]
> **For bachelor's, master's and PhD theses, seminar papers and reports, use the official JKU template:**
> **<https://github.com/michaelroland/jku-templates-report-latex>**
>
> Documentation and the latest version are on its [releases page](https://github.com/michaelroland/jku-templates-report-latex/releases/latest). 

This repository now maintains only one template: the **PhD exposé** of the Institute of Business Informatics – Software Engineering (WIN-SE), Johannes Kepler University Linz.

| Folder | Status | Use it for |
|---|---|---|
| [`phd_expose/`](phd_expose) | **Maintained** | PhD exposé / research proposal |
| [`legacy/bac_master/`](legacy/bac_master) | Deprecated, no longer maintained | Kept for existing theses only |
| [`legacy/seminar/`](legacy/seminar) | Deprecated, no longer maintained | Kept for existing seminar papers only |

If you've already started a document with one of the legacy templates, you can finish it there. For anything new, use the official template.
